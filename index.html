AWS Employee Management Application

A hands-on cloud deployment project built with Python Flask and AWS EC2.

Project Overview

This project demonstrates deploying a Flask application on Ubuntu EC2 using Gunicorn as the application server and Nginx as a reverse proxy.

Technologies: AWS EC2, Ubuntu, Python, Flask, Gunicorn, Nginx, systemd and Git.

Application Features

  • Employee directory web page
  • JSON API endpoint: /api/employees
  • Health-check endpoint: /health
  • Linux service management with systemd

Architecture

Browser → Nginx → Gunicorn → Flask Application

The current learning deployment runs on one EC2 instance. PostgreSQL integration and further tier separation are planned.
